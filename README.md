# conceitos-criacao-de-maquinas-virtuais
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO

Além dos conceitos para criação de máquinas virtuais no ambiente da azure, foi fornecido informações sobre os beneficios importantes fornecidos pela azure para empresas, como o serviço de alta disponibilidade e como está relacionada com as máquinas virtuais e todos os recursos fornecidos para a criação.
 Após esta aprendizagem na dio, foi recomendado a base de conhecimentos da microsoft para criação da máquina virtual: https://learn.microsoft.com/pt-br/azure/virtual-machines/windows/quick-create-portal
 O que ajudou a consolidar conhecimento além de ser uma base 100% orientada pela microsoft.
